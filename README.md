# Laboratorio 08 - Destinos Turísticos con Django

## Descripción

Aplicación web desarrollada en Django para la gestión y visualización de destinos turísticos del Perú.

La aplicación permite registrar destinos turísticos con información como:

* Nombre de la ciudad
* Descripción
* Imagen
* Precio del tour
* Oferta disponible

Los datos son administrados mediante el panel de administración de Django y mostrados dinámicamente en la página principal utilizando Django Template Language.

## Tecnologías utilizadas

* Python
* Django
* HTML
* CSS
* SQLite
* Git y GitHub

## Funcionalidades

* Registro de destinos turísticos.
* Modificación de destinos turísticos.
* Eliminación de destinos turísticos.
* Visualización dinámica de destinos.
* Uso de tags `for` e `if`.
* Administración mediante Django Admin.

## Ejecución del proyecto

Activar el entorno virtual:

```bash
source env/Scripts/activate
```

Ejecutar el servidor:

```bash
python manage.py runserver
```

Abrir en el navegador:

```text
http://127.0.0.1:8000/
```
